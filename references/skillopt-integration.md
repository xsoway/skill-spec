# SkillOpt 集成规范

SkillOpt 是候选文本优化器，不是自动发布器。只有满足以下条件的 Skill 才可进入训练：

1. 稳定基线已版本化；
2. 不可训练合同与可训练种子分离；
3. 数据脱敏、获批，并隔离训练/验证/留出集；
4. 有可重复的评分函数和晋升阈值；
5. 候选与稳定版本可回滚，且有人工审批人。

`skillopt.py preflight` 只检查上述准备度。`run --execute` 仅在本机已安装 Python `skillopt` 包、给出配置且用户明确授权时调用训练。训练产物默认在 `.skillopt-workspaces/`；不得自动覆盖 `SKILL.md`、Prompt 或稳定版本。

晋升记录必须包含：基线版本、候选版本、训练/验证/留出集 ID、指标对比、退化检查、审批人、回滚位置和日期。
